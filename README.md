# ChatGPT 右侧问题导航（原版小横线模式）

这是一个**完全本地运行**的 Chrome / Microsoft Edge 扩展，提供旧版 ChatGPT 风格的右侧小横线问题导航。

## 功能

- 右侧垂直的小横线，每条代表当前网页**已加载的**一条用户提问。
- 将鼠标放到横线上显示问题摘要。
- 点击横线即可将聊天滚动到对应提问；当前所在问题高亮。
- 横线固定长度与位置，悬停和高亮仅改变颜色，不播放伸缩动画。
- 自动识别新发送的提问，适配深色和浅色主题。
- 安装或更新后自动在已打开的 ChatGPT 页面加载；点击扩展图标可重新加载导航。
- 不展开目录、不主动加载以前的消息、不调用 ChatGPT API。
- 仅申请在 ChatGPT 页面注入导航所需的权限，不申请浏览器存储权限、不发送对话内容。

## 安装（Edge）

1. 在 GitHub 仓库点击 **Code → Download ZIP**，下载并解压；也可运行 `git clone https://github.com/Hejt412/ChatGPT-Navigator.git`。
2. 在 Edge 地址栏打开 `edge://extensions/`。
3. 开启左侧的「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择包含 `manifest.json` 的目录，例如解压后的 **ChatGPT-Navigator-main**，或克隆得到的 **ChatGPT-Navigator** 文件夹。
5. 打开 `https://chatgpt.com/`。已打开的聊天会自动加载导航；如果没有出现，刷新聊天页面一次。

## 安装（Chrome）

步骤相同，但扩展管理地址改为 `chrome://extensions/`。

## 使用

在 ChatGPT 中打开含有用户提问的聊天，右侧自动出现导航短横线。鼠标放在横线上显示对应问题，点击即可跳转。长聊天中的导航横线本身可以滚动。

## 已安装，但旧对话没有导航

1. 更新本文件夹代码后，在 `edge://extensions/` 找到「ChatGPT 右侧问题导航」，点击该扩展卡片上的重新加载按钮。Chrome 使用 `chrome://extensions/`。
2. 如果浏览器提示新增权限，允许扩展在 `chatgpt.com` 使用，再回到聊天页面刷新一次。
3. 也可以在 ChatGPT 页面点击浏览器扩展菜单中的「ChatGPT 右侧问题导航」图标，重新加载导航。
4. 若浏览器把站点访问设为「单击时」，请改为允许在 `chatgpt.com` 使用，否则无法自动加载。

旧版 1.0.0 只在页面整页加载时注入脚本，安装前就已打开的标签页需要手动刷新；只从左侧切换对话不会触发整页加载。1.0.1 已增加安装/更新后的自动注入，并修复导航节点被页面移除后的恢复、切换到空对话时的清理，兼容 `data-turn="user"` 消息标记。

1.0.2 根据实际页面新增对 `data-user-message-bubble="true"`、以 `:user` 结尾的 `data-content-search-unit-key` / `data-chatgpt-search-unit-key` 的识别。该页面已不含旧版的三种用户角色标记；旧选择器会找到 0 条提问并隐藏导航。同一条提问上的嵌套标记会合并为一条，跳转定位到完整用户消息单元。

重新注入脚本时也会检查实例版本：升级会替换旧实例，同版本只重新扫描，避免旧版的「已经加载」标志阻止修复代码生效。

1.0.3 将横线统一固定为 24 × 3 像素，移除悬停、聚焦和当前问题切换时的宽度、粗细变化及伸缩动画，避免左右抖动。

## 已知限制

- **仅索引当前网页 DOM 中已渲染的用户问题**。尚未加载或已经被网页虚拟列表卸载的问题，不会显示，因而无法直接跳转。
- ChatGPT 若调整网页结构（包括用户角色、用户气泡和搜索单元属性），扩展可能需要更新选择器。
- 导航栏较靠右，如果浏览器窗口过窄，可能与 ChatGPT 自身按钮略有重叠。
- 这是独立制作的本地插件，并非 OpenAI 官方产品。

## 隐私

`manifest.json` 声明 `scripting` 权限及仅限 `https://chatgpt.com/*`、`https://chat.openai.com/*` 的站点权限，用于在安装、更新或点击图标时向已打开的 ChatGPT 页面注入导航。后台只查询这两个站点的标签页，不申请 `tabs`、存储或 Cookies 权限。脚本只读取当前页面已渲染的消息，并在浏览器内显示导航，不发起网络请求。

## 文件

- `manifest.json`：扩展信息及生效网址。
- `background.js`：安装/更新时自动注入，以及点击扩展图标重新加载。
- `content.js`：导航栏全部逻辑及隔离样式。
- `icons/`：扩展图标。

版本：1.0.3

## 开发验证

- 后台注入与权限回归：`node --test tests/background.test.cjs`。
- 浏览器回归：先安装开发依赖 `npm install --no-save playwright-core`，再运行 `node tests/content.browser.cjs`。默认使用 Windows 的 Edge 安装路径；可用 `EDGE_PATH` 指定浏览器路径，`PLAYWRIGHT_MODULE` 指定已有的 `playwright-core` 模块路径。
- 浏览器用模拟聊天页面验证旧对话切换、消息识别、悬停预览、跳转和导航恢复，不访问个人对话。
